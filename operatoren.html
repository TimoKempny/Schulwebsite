Vergleichsoperatoren

Ein Vergleich stellt eine Ja/Nein-Frage über zwei Werte. Das Ergebnis ist ein Wahrheitswert: in Python True (wahr) oder False (falsch) vom Typ bool. in C eine ganze Zahl (int): 1 für wahr, 0 für falsch.

Beispiel mit x = 7 und y = 3:

OperatorBedeutungBeispielErgebnis
==gleichx == 7
!=ungleichx != y
<kleiner alsx < y
>größer alsx > y
<=kleiner oder gleichx <= 7
>=größer oder gleichy >= 5

= oder == ? = ist eine Zuweisung („x bekommt den Wert 5“), == ist ein Vergleich („ist x gleich 5?“). In einer Bedingung führt if x = 5: in Python zu einem SyntaxError. if (x = 5) wird in C trotzdem kompiliert, weist 5 zu und ist damit immer wahr. Genau deshalb ist dieser Fehler so tückisch.

Merkregel Bei <=, >= und != steht das Gleichheitszeichen immer hinten. =< oder => gibt es nicht.

Vergleichsketten Python erlaubt 1 < x < 10 wie in Mathe. Gemeint ist damit 1 < x and x < 10. Achtung: Das klappt nur in Python, in C bedeutet es etwas ganz anderes.

Keine Vergleichsketten! 1 < x < 10 wird in C von links gerechnet: erst 1 < x (ergibt 0 oder 1), dann 0 < 10 bzw. 1 < 10, und das ist immer wahr. Richtig ist: x > 1 && x < 10.

Texte vergleichen name == "Max" funktioniert in Python direkt. Groß- und Kleinschreibung zählen: "max" == "Max" ist False.

Texte vergleichen Strings vergleicht man in C nicht mit ==, sondern mit strcmp(name, "Max") == 0 aus <string.h>.

Kommazahlen 0.1 + 0.2 == 0.3 ist falsch, weil Kommazahlen nur ungefähr gespeichert werden. Vergleiche besser mit Toleranz: abs(a - b) < 1e-9fabs(a - b) < 1e-9.

Logische Operatoren

Mit logischen Operatoren verknüpft man mehrere Bedingungen zu einer.

PythonCNamewahr, wenn …
and&&UNDbeide Seiten wahr sind
or||ODERmindestens eine Seite wahr ist
not!NICHTder Wert falsch ist (dreht um)

Die jeweils andere Sprache steht zum Vergleich daneben.

Beispiel aus dem Alltag

Ins Kino (FSK 16) darf, wer mindestens 16 ist oder in Begleitung kommt:

alter = int(input("Alter: "))
begleitung = input("Mit Begleitung? (j/n) ") == "j"

if alter >= 16 or begleitung:
    print("Viel Spaß im Film!")
else:
    print("Leider erst ab 16.")
#include <stdio.h>

int main(void) {
    int alter;
    char antwort;
    printf("Alter: ");
    scanf("%d", &alter);
    printf("Mit Begleitung? (j/n) ");
    scanf(" %c", &antwort);
    int begleitung = (antwort == 'j');

    if (alter >= 16 || begleitung) {
        printf("Viel Spass im Film!\n");
    } else {
        printf("Leider erst ab 16.\n");
    }
    return 0;
}

Was zählt als wahr? Außer True/False gelten auch 0, "" (leerer Text), [] (leere Liste) und None als falsch. Alles andere ist wahr. C hat ursprünglich keinen eigenen Wahrheitstyp: 0 ist falsch, jeder andere Wert ist wahr. Mit #include <stdbool.h> gibt es bool, true und false, dahinter stecken aber trotzdem 1 und 0.

De Morgan not (a and b) ist dasselbe wie not a or not b.
not (a or b) ist dasselbe wie not a and not b. !(a && b) ist dasselbe wie !a || !b.
!(a || b) ist dasselbe wie !a && !b. Zieht man das NICHT in die Klammer, wird aus UND ein ODER und umgekehrt.

Vorrang & Kurzschluss

Was wird zuerst ausgewertet?

Von oben (zuerst) nach unten (zuletzt):

  1. Klammern ( )
  2. Rechnen: * / %, dann + -
  3. Vergleiche: == != < > <= >=
  4. not
  5. and
  6. or
  1. Klammern ( )
  2. ! und Vorzeichen -
  3. Rechnen: * / %, dann + -
  4. < > <= >=
  5. == !=
  6. &&
  7. ||

Merke: UND bindet stärker als ODER, wie Punkt- vor Strichrechnung. a or b and c heißt a or (b and c). a || b && c heißt a || (b && c).

not steht tiefnot x > 5 bedeutet not (x > 5), weil der Vergleich zuerst ausgewertet wird.

! steht hoch!x > 5 bedeutet (!x) > 5 und nicht !(x > 5). Setze bei ! lieber Klammern.

TippIm Zweifel Klammern setzen. Das kostet nichts und macht den Code lesbarer.

Kurzschluss-Auswertung

Logische Ausdrücke werden von links nach rechts ausgewertet. Sobald das Ergebnis feststeht, hört das Programm auf:

  • False and …0 && … ist auf jeden Fall falsch. Die rechte Seite wird nicht mehr angesehen.
  • True or …1 || … ist auf jeden Fall wahr. Auch hier wird rechts nichts mehr ausgewertet.

Das ist praktisch, um Fehler zu vermeiden. Die Prüfung muss dafür vorne stehen:

if y != 0 and x % y == 0:     # sicher
    print("y ist ein Teiler von x")

if x % y == 0 and y != 0:     # ZeroDivisionError bei y = 0!
if (y != 0 && x % y == 0) {   /* sicher */
    printf("y ist ein Teiler von x\n");
}

if (x % y == 0 && y != 0) {   /* Absturz bei y = 0! */

Probier es im Labor aus: Setze y = 0 und wähle die Vorlage „Kurzschluss“.

Ausdruck-Labor

Gib einen Ausdruck mit x, y und z ein. Das Labor zeigt Schritt für Schritt, wie PythonC ihn auswertet. Erlaubt sind ganze Zahlen, + - * %, Vergleiche, and or not True False&& || ! true false und Klammern.
